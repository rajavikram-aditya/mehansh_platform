## Brand guideline findings from reviewed PDF pages 1–6
The brand guidelines establish a polished system that should override any generic web template styling. The stated brand expression is “Quiet, operational, confident.” The identity is described as balancing editorial warmth with operational clarity: serif headlines provide character, while a disciplined sans-serif system keeps navigation and interface content direct and easy to use.

The visual system is built on three core signals. First, **trust and calm through navy and cream**. Second, **one controlled spark of energy through lime**. Third, **modular service thinking through muted pastel blocks**. The document explicitly frames color as a hierarchy, not decoration.

The primary palette shown is:

| Role | Color | Hex |
|---|---|---|
| Foundation dark | Navy | #1F3A52 |
| Foundation light | Cream | #F2EDE3 |
| Accent | Lime | #D6FF3B |
| Accent support | Lime Pale | #E7F2A7 |

The supporting blocks shown are muted and refined rather than saturated:

| Supporting block | Hex |
|---|---|
| Soft grey | #A7ADAF |
| Light aqua | #A2DCD9 |
| Soft lavender | #C8B0E1 |
| Deep teal | #19687A |
| Olive green | #5E7E49 |

A usage rule in the guidelines states that **lime is an accent only**. It should never be used as body text or a large fill. The rhythm should stay disciplined, with only one dominant lime element per viewport.

Typography is explicitly defined. Headlines use **Fraunces**, described as a warm, high-contrast serif for H1–H2 moments and occasional italic emphasis. Body, interface, and navigation use **Inter**, described as a clean, neutral sans-serif for navigation, descriptions, controls, and labels. The desktop type scale shown is Display 80px / 0.95, H1 56px / 1.0, H2 40px / 1.05, H3 28px / 1.15, Body Large 18px / 1.5, Body 16px / 1.6, and Label 12px / 1.4 with tracking.

Spacing is also prescribed. The system is built on a strict **8px baseline grid**. Section vertical padding is set to **140px on desktop** to create calm editorial transitions. Card grids use **24–32px gutters**, while side gutters are maintained at **64–80px on desktop**. Thin **1px hairline dividers** should separate navigation, labels, and content blocks, providing structure without noise.
